# Бот-конспектор лекций

Пришлите запись лекции или её расшифровку — бот сделает конспект в аккуратном оформлении: PDF или сообщениями в Telegram.

## Что умеет

- **Вход:** голосовое, аудио или видео с речью (до 20 МБ — лимит Telegram), текст сообщением или файл `.txt`.
- **Распознавание и конспект:** один провайдер, Gemini API. Запись отдаётся модели напрямую, текст расшифровки получается из неё же, затем модель пишет конспект по схеме. Редакторский стандарт — из скилла `notion-lecture-notes`: 8–15% от исходника, мало списков, цветные блоки.
- **Настройки** (команда `/settings`):
  - **Формат:** PDF-файл или сообщения Telegram в MarkdownV2. Длинный конспект режется на части по 4096 знаков.
  - **Длина:** короткий, средний или подробный.
  - **Оформление PDF:** шесть палитр или свой HEX-цвет (например `#3B82F6`).
  - **Блоки:** каждый из 10 блоков можно включить или выключить. Это главная идея, контекст, ключевые понятия, модель или процесс, различия, примеры, важно и ловушки, практическое применение, «Что запомнить», вопросы для самопроверки.

## Бесплатный тариф и данные

Gemini API имеет бесплатный тариф, карта не нужна. Но у него есть два условия, которые важно знать до запуска:

- **Данные могут использоваться.** На странице тарифов Google для бесплатного плана написано «Content used to improve our products»: содержимое запросов может использоваться для улучшения продуктов. Для учебных записей это обычно не критично. Если в записях есть персональные данные или материалы, которые нельзя передавать третьим лицам, используйте платный тариф и проверьте его условия в документации.
- **Квоты ограничены.** Лимиты (запросов в минуту и в день) зависят от модели и проекта. Актуальные значения смотрите в [AI Studio](https://aistudio.google.com/rate-limit). Когда квота исчерпана, бот пишет об этом и не падает. Сутки квоты сбрасываются в полночь по тихоокеанскому времени.

Какие модели входят в бесплатный тариф, меняется со временем. Проверьте в AI Studio, какая модель есть в вашем проекте, и укажите её в `GEMINI_MODEL`. По умолчанию стоит `gemini-2.5-flash`.

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и возьмите токен.
2. Создайте ключ Gemini в [Google AI Studio](https://aistudio.google.com/apikey).
3. Установите зависимости:

   ```bash
   python -m venv .venv && . .venv/bin/activate
   pip install -r requirements.txt
   ```

   Для PDF нужны Pango и шрифты. На Debian или Ubuntu:

   ```bash
   sudo apt install libpango-1.0-0 libpangoft2-1.0-0 libharfbuzz-subset0 fonts-inter fonts-noto-color-emoji
   ```

4. Заполните настройки и запустите:

   ```bash
   cp .env.example .env   # впишите токен бота и ключ Gemini
   set -a; . ./.env; set +a
   python -m notes_bot
   ```

Настройки пользователей хранятся в SQLite-файле в `DATA_DIR` (по умолчанию `data/`).

## Тесты

```bash
pip install -r requirements-dev.txt
pytest
```

Тесты не ходят в сеть. Gemini для тестов подменяется локальным HTTP-сервером, который записывает запросы SDK и отдаёт заготовленные ответы. Telegram тоже заменён заглушками. Сквозной сценарий на настоящих ключах нужно проверить отдельно.

## Как устроено

```
аудио ──► Gemini (расшифровка) ──► текст ──► Gemini (JSON по схеме, только включённые блоки) ──► NoteDocument
                                                                                                  │
                                                  ┌───────────────────────────────────────────────┴───┐
                                                  ▼                                                   ▼
                                   PDF: Jinja2 HTML + WeasyPrint                  MarkdownV2: сообщения ≤ 4096
                                   (палитра темы → CSS)                           (экранирование, разбиение)
```

| Модуль | Что делает |
| --- | --- |
| `blocks.py` | Десять блоков конспекта, их порядок и цветовые роли, пресеты длины |
| `themes.py` | Палитры, проверка HEX, осветление цветов |
| `settings.py` | Настройки пользователя и их хранение в SQLite |
| `notes.py` | Модель конспекта, JSON-схема ответа для Gemini, системный промпт |
| `gemini.py` | Клиент Gemini: расшифровка, конспект, загрузка больших файлов, понятные ошибки |
| `pipeline.py` | Аудио или текст → конспект → результат нужного формата |
| `render_pdf.py`, `templates/` | Вёрстка PDF |
| `render_tg.py` | MarkdownV2 и разбиение сообщений под лимит Telegram |
| `menus.py`, `bot.py` | Inline-меню настроек и хендлеры Telegram |

## Ограничения

- Telegram не отдаёт боту файлы больше 20 МБ. Длинную запись перед отправкой сожмите: моно, Opus 32 кбит/с — это примерно 14 МБ на час.
- Запросы до 12 МБ уходят в Gemini целиком. Файлы крупнее загружаются через Files API и удаляются после расшифровки.
- Gemini принимает записи до 9,5 часа в одном запросе, форматы ogg, mp3, m4a, wav, flac, aac, webm и mp4.
- Если `ALLOWED_USER_IDS` пуст, пользоваться ботом может любой и тратить вашу квоту. Укажите свой ID Telegram: бот покажет его, если вы не в списке.
- Цвета применяются только к PDF. В сообщениях Telegram оформление — эмодзи и жирный шрифт.
